# PWA з посиланням для iOS

## Що зроблено
- PWA-сторінка з кнопкою відкриття посилання.
- Кнопка з інструкцією, як додати PWA на початковий екран iOS.
- `manifest.webmanifest` для встановлення застосунку.
- `sw.js` для кешування базових файлів.

## Де змінити ваше посилання
Відкрийте файл `app.js` і змініть:

```js
const REDIRECT_BASE_URL = "https://visitygo.io/7jZssN";
```

Усі параметри автоматично додаються із cookies/дефолтів.

## Які параметри зберігаються в cookies
`c`, `saff_id`, `http_referer`, `utm_source`, `utm_campaign`, `utm_medium`, `utm_content`, `utm_term`, `clickid`, `pid`

Якщо параметр прийшов у URL, він зберігається в cookie на 30 днів.
Якщо в cookie порожньо — використовується дефолт із `DEFAULT_LINK`.

## Push-підписка
Під час запуску в standalone PWA:
1. застосунок запитує дозвіл на push;
2. пробує підписати користувача через `PushManager`;
3. робить редірект на оффер-посилання з параметрами.

Для реальної push-підписки додайте ваш VAPID public key у:

```js
const PUSH_PUBLIC_VAPID_KEY = "";
```

## Як запустити локально
PWA не працює коректно через `file://`, потрібен локальний сервер.

Наприклад:

```bash
python3 -m http.server 8080
```

Потім відкрийте:
`http://localhost:8080`

## Як додати на iOS
1. Відкрити сторінку в Safari.
2. Натиснути Поділитися.
3. Обрати "На екран «Початковий»".
4. Натиснути "Додати".
